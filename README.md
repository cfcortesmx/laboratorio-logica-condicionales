## 🎯 Objetivo de Aprendizaje

El objetivo de este laboratorio virtual es proporcionar un entorno interactivo y autocalificable para que los estudiantes de educación superior desarrollen competencias sólidas en el diseño e implementación de estructuras de control de flujo condicional simples, compuestas y anidadas en TypeScript, verificando la consistencia algorítmica mediante pruebas unitarias automatizadas (TDD).

---

## 📚 Estructura de Módulos Prácticos

El recurso se organiza en 4 módulos progresivos:

1. **Módulo 1: Operadores Lógicos y Tablas de Verdad**
   * Evaluación de operadores booleanos fundamentales (`AND`, `OR`, `XOR`, `NAND`).
   * Verificación exhaustiva de tablas de verdad mediante aserciones formales.
2. **Módulo 2: Clasificación y Evaluación de Rangos Numéricos**
   * Evaluación de signos y paridad con condiciones de frontera (cero, enteros positivos y negativos).
3. **Módulo 3: Validador y Clasificador Geométrico de Triángulos**
   * Implementación del teorema de la desigualdad triangular y clasificación condicional múltiple (*equilátero*, *isósceles*, *escaleno*, *inválido*).
4. **Módulo 4: Sistema de Tarifas con Precedencia de Condiciones Compuestas**
   * Lógica de toma de decisiones jerárquica basada en edad, rol estudiantil y membresías.

## ⚡ Guía de Instalación y Uso para Estudiantes

### 1. Requisitos Previos
* **Node.js** (versión 18.0 o superior).
* **Git**.

### 2. Clonar el Laboratorio
```bash
git clone https://github.com/cfcortesmx/laboratorio-logica-condicionales.git
cd laboratorio-logica-condicionales
npm install
```

### 3. Ejecutar las Pruebas y Validación
Para verificar la solución y obtener retroalimentación instantánea:
```bash
npm test
```

Para modo de desarrollo interactivo (re-ejecución automática al guardar cambios):
```bash
npm run test:watch
```
